How should the messages sound?

Tone changes the voice — the greeting, the sign-off, the connective phrasing. It never changes the evidence rules, the offer, or the legal footer, and it can never make a message quote the customer’s numbers back at them. Save, then read a few on the Messages screen; every message stays hand-editable before you approve it.

The offer catalogue

Offers live in categories because the right nudge for a daily coffee regular is nonsense for a Friday-night group. Edit the list, add your own, then choose which offer each rule uses underneath.
