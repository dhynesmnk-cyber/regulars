Where will these go out from?

Regulars writes the messages; something else has to send them. Tell us what you already use and the export adapts to it — including the unsubscribe merge tag, which is different in every tool and is not a cosmetic detail.

Square connection (OAuth)

Square OAuth is not configured on this server yet. Set SQUARE_CLIENT_ID, SQUARE_CLIENT_SECRET and REGULARS_REDIRECT_URI in the environment (the application is free to create in the Square Developer Dashboard), and the connect button here will run the real authorization-code flow. Until then, use the CSV upload on the Setup screen — it needs no credentials at all.

What changes in the export

Footer unsubscribe tag: {{unsubscribe_url}} — rewritten automatically when you pick a sender above. Columns: Email, First Name, Last Name, Subject, Body, Offer, Offer Category, Trigger, Consent Source, Consent Date, Holdout.

The holdout column marks every tenth person. Do not send to them. They are the control group that lets you prove any of this worked, and comparing the venue total before-and-after without them overstates everything.
